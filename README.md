# 1C-Fresh-Invoice-BoxesPrintForm
Расширение для 1С:Fresh. Доработка создание новой печатной формы накладной с отображением количества коробок без изменения типовой конфигурации.

## О проекте

Данный проект представляет собой расширение для 1С:Fresh, разработанное без изменения типовой конфигурации.

Цель доработки — отображение количества коробок в накладной. В информационной базе количество товара хранится в килограммах, однако заказчику требовалось видеть количество коробок при в накладных.

---

## Постановка задачи

Необходимо реализовать вывод количества коробок в новой печатной форме накладной, при этом:

- не изменять типовую конфигурацию;
- использовать только механизм расширений;
- обеспечить совместимость с 1С:Fresh.

---

## Реализованное решение

В рамках проекта было выполнено:

- создано расширение конфигурации;
- добавлен реквизит ВесКоробки в справочник Номенклатура через расширение;
- доработан существующий макет печатной формы;
- реализован расчет количества коробок по формуле;
- обеспечена работа без изменения типовой конфигурации;
- расширение успешно прошло аудит 1С:Fresh и было опубликовано для использования заказчиком.

---

## Используемые технологии

- 1С:Предприятие 8.3
- Расширения конфигурации
- 1С:Fresh
- Макеты печатных форм
- Справочник «Номенклатура»

---

## Результат

В результате пользователь получает печатную форму накладной, в которой дополнительно отображается количество коробок, рассчитанное на основании веса товара и веса одной коробки.
